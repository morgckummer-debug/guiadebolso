# Pensamentos guardados — inbox da autora

Toda vez que a Dra. Morgana escrever `Pensamento: …` em conversa, o texto é
salvo aqui como está (sem editar), com a data. Isso é matéria-prima solta —
ainda sem tema definido. Quando um Tema relacionado for criado, o
pensamento correspondente é promovido para o campo `aprendi:` daquele Tema
em `prototype/index.html` (ver `docs/05-banco-perguntas-pessoais.md` para o
fluxo de coleta por tema) e marcado como usado aqui, sem apagar o registro
original.

Formato de cada entrada: data, texto literal, status (`novo` / `usado em:
<tema>`).

  algum ponto do app, possivelmente ligado à Aula Express, pra ensinar o
  médico a olhar o laudo com mais atenção).
